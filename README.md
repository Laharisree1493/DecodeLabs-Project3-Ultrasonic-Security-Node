## 📌 Project Overview
This project implements an industrial-grade **Autonomous Irrigation Controller** centered on the ESP32 microcontroller. The system reads analog telemetry from a soil moisture interface, applies real-time software signal conditioning, and executes closed-loop hysteresis threshold control to switch an opto-isolated 5V relay module driving a simulated irrigation pump.

---

## ✨ Features & Engineering Highlights
* **Exponential Moving Average (EMA) Signal Filtering:** Employs an EMA algorithm combined with oversampling to eliminate high-frequency ADC noise generated by internal ESP32 switching circuits[cite: 1].
* **Hysteresis Deadband Logic:** Implements dynamic upper (45%) and lower (30%) threshold gates to eliminate mechanical relay chattering, preventing contact welding and motor thermal stress[cite: 1].
* **Safe Active-LOW Bootup Sequence:** Solves hardware floating pin vulnerabilities during MCU startup by explicitly pulling output pins HIGH prior to declaring pin mode initialization[cite: 1].
* **Galvanic Isolation Protection:** Integrates optocoupler separation to protect MCU silicon against high-voltage Back-EMF inductive voltage spikes[cite: 1].

## 💻 Source Code (`sketch.ino`)

```cpp
#include <Arduino.h>

#define MOISTURE_PIN 34
#define RELAY_PIN 26

// Thresholds for Hysteresis
const int T_ON = 30;   // Moisture threshold to turn pump ON
const int T_OFF = 45;  // Moisture threshold to turn pump OFF

// EMA Filter Variables
float filteredMoisture = 0.0;
const float ALPHA = 0.15; // Filter smoothing factor

bool pumpState = false; // false = OFF, true = ON

void setup() {
  Serial.begin(115200);

  // Active-LOW Safe Startup
  digitalWrite(RELAY_PIN, HIGH); 
  pinMode(RELAY_PIN, OUTPUT);

  // Initial ADC Read
  int rawADC = analogRead(MOISTURE_PIN);
  filteredMoisture = map(rawADC, 0, 4095, 0, 100);

  Serial.println("==========================================");
  Serial.println(" Automated Irrigation Controller Started ");
  Serial.println("==========================================");
}

void loop() {
  // Read Analog Soil Moisture Sensor
  int rawADC = analogRead(MOISTURE_PIN);
  float currentMoisture = map(rawADC, 0, 4095, 0, 100);

  // Exponential Moving Average (EMA) Filtering
  filteredMoisture = (ALPHA * currentMoisture) + ((1.0 - ALPHA) * filteredMoisture);

  // Closed-loop Hysteresis Control Logic
  if (filteredMoisture < T_ON && !pumpState) {
    pumpState = true;
    digitalWrite(RELAY_PIN, LOW); // Active-LOW Relay ON
    Serial.println("DRY SOIL DETECTED -> Pump Activated (RELAY ON)");
  } 
  else if (filteredMoisture > T_OFF && pumpState) {
    pumpState = false;
    digitalWrite(RELAY_PIN, HIGH); // Active-LOW Relay OFF
    Serial.println("OPTIMAL MOISTURE REACHED -> Pump Deactivated (RELAY OFF)");
  }

  // Telemetry Output
  Serial.print("Moisture Level: ");
  Serial.print(filteredMoisture);
  Serial.print("% | Pump State: ");
  Serial.println(pumpState ? "ON" : "OFF");

  delay(1000);
}
